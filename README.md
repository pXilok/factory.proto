# Factorio 3D Proto

Упрощённый прототип Factorio на C++ / raylib с 3D-рендером.

## Что за игра

Добывай руду → вези конвейером → плавь в пластины → защищай базу от волн врагов.
Переживи 5 волн и накопи максимум пластин.

## Механики

- Добыча руды (железо, медь) бурами
- Транспортировка конвейерами
- Плавка руды в пластины
- Апгрейд бура (клавиша U) за 5 пластин — скорость добычи ×2 за уровень
- 4 типа врагов: обычный, быстрый, танк, **босс** (каждая 3-я волна)
- Турели автоматически отстреливают врагов в радиусе
- HP базы (100), разрушаемые здания
- 5 волн, победа/поражение
- День/ночь, частицы, screen shake, damage numbers
- Миникарта в углу

## 3D-графика

- Настоящая 3D-камера (перспектива) над картой
- Вращение камеры клавишами Q / E
- Приближение/отдаление колесом мыши
- Все здания — объёмные примитивы (цилиндры, кубы, сферы)
- Тени, свечения, анимации

## Управление

| Клавиша | Действие |
|---------|----------|
| 1 | Бур (ставится на руду) |
| 2 | Конвейер |
| 3 | Плавильня |
| 4 | Турель (10 пластин) |
| 5 | Удалить |
| R | Повернуть постройку |
| ПКМ | Повернуть готовое здание |
| U | Апгрейд бура |
| Q / E | Вращение камеры |
| Колесо мыши | Приблизить/отдалить |
| P | Пауза |
| F5 / F9 | Сохранить / загрузить |
| ESC | В меню |

## Меню

- **New Game** — начать заново
- **Continue** — продолжить с сохранения (если есть)
- **Records** — таблица рекордов (топ-5)
- **Settings** — громкость
- **Exit** — выход
